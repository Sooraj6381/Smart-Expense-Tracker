
# Smart Expense Tracker with Graphical Analytics

A full-stack web application built using Python Flask and MySQL to manage personal income, expenses, and monthly budgets.

## Features

- User Registration and Login
- Secure Password Hashing
- Dashboard with Financial Summaries
- Add, Edit and Delete Transactions
- Monthly Budget Management
- Reports and Graphical Analytics
- Search and Filter Transactions
- CSV and PDF Export
- Profile Management
- Change Password
- Multi-user Data Isolation

## Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Chart.js
- Flask-Login
- Flask-WTF

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Create a `.env` file using the required environment variables.
5. Configure your MySQL database.
6. Run the application:

   python app.py

7. Open http://127.0.0.1:5000 in your browser.

## Security

Never upload `.env`, database passwords, secret keys, or private user data to GitHub.
